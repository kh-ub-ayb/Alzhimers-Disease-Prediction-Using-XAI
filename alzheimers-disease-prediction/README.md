# 🧠 Alzheimer's Disease Prediction Using Deep Learning

An AI-powered Alzheimer's Disease Prediction system that classifies MRI brain images into different stages of Alzheimer's disease using deep learning models and provides real-time prediction through a Flask web application.

---

## 🚀 Features

- Multi-class Alzheimer's disease classification
- MRI brain image analysis
- Deep learning-based prediction
- Explainable AI using Grad-CAM and LIME
- Real-time Flask web application
- Performance evaluation and model comparison

---

## 🏃‍♂️ How to Run

1. Navigate to the project code directory:

```powershell
cd "d:\New folder\PROJECTS\MajorProject\alzheimers-disease-prediction\Project Code"
```

2. Run the application:

```powershell
& "d:\New folder\PROJECTS\MajorProject\.venv\Scripts\python.exe" app.py
```

3. Open your browser and go to: http://127.0.0.1:5000
